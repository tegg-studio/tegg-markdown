# Attribution illustration sources

These five English concept images were edited with the built-in imagegen tool
on 2026-09-14 from the project-owned accepted attribution designs. They illustrate
Host layouts, not a shipped customer product or tested SDK presets. The fictional
application is named Workspace. No private customer documents are included.

Images are maintained here alongside the [public guide](../../attribution-guide.md).
They are distributed as project documentation under the repository [license](../../../LICENSE).

Preserve canvas, layout, spacing, colors, icons, visual hierarchy, and exactly the existing attribution position and style. Translate ALL Chinese text into crisp natural English including navigation, document body, table, buttons, avatar. No Chinese characters anywhere. Customer demo name: "Workspace". Sections: "This week's plan", "Key milestones". Plan summary: "Focus on core tasks and keep the project moving." Checklist: "Review requirements and confirm scope", "Create the first design draft", "Align the technical approach". Table: "Phase", "Goal"; "Discovery", "Confirm requirements and scope"; "Design", "Create prototypes and designs"; "Development", "Build and test core features"; "Launch", "Release and gather feedback". Footer if present: "Saved · 328 words". Preserve exact text "Powered by Tegg Markdown" and its full legibility. These are fictional example UI illustrations, no additional badges or annotations. Reflow English as needed without overlaps.

Per-image additions:

- `status-bar.png`: no additional prompt.
- `component-footer.png`: Form translations: "Projects", "Knowledge base", "New document", "Create a project document", "Keep goals, plans and progress together.", "Title", "Content", "Markdown supported", "Create document", "Cancel".
- `sidebar.png`: no additional prompt.
- `corner-signature.png`: Top button: "Edit document". If milestone paragraph present: "Align on each milestone and keep the project on track." Keep attribution at bottom right; keep its subtle gray rounded background.
- `watermark-corner-small.png`: Top button: "Edit document". If milestone paragraph present: "Align on each milestone and keep the project on track." Keep attribution at bottom right; keep it SMALL two lines, right aligned, gray text, NO background border or shadow.

The outputs were visually reviewed for English text, the generic Workspace name,
the complete attribution and the five distinct placements. Image-generation layout
and text variations are illustrative; exact parameters are specified in the guide.
