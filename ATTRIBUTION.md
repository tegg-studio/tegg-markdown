# Required attribution

The binding requirements are in [LICENSE](LICENSE), sections 3–5.

- Display **Powered by Tegg Markdown** while the relevant reader/editor is visible.
- The default SDK frame keeps a footer outside the scrolling document.
- A visible adjacent toolbar or status bar is also acceptable. One clear shared
  attribution can cover multiple simultaneous instances on the same screen.
- Adapt typography and theme while preserving legibility and accessibility.
- An About page, hidden menu, off-screen footer or transparent text is insufficient.
- Linking to this repository is encouraged, not required.
- Headless usage places the text in accompanying user documentation or notices.
- Do not inject attribution into Markdown source, saved files or exported output.
- A fork or wrapper still carries the same obligations for the covered code.

The advanced `attribution: "host"` option transfers placement to the Host;
it is not an exemption. The Host must provide a compliant visible attribution
or possess a separate written white-label grant. There is no secret key and
no enforcement telemetry. Legal permission and UI configuration are separate.
